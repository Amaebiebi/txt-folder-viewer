# 2026/11/24
調べたこと
fxmlファイルを作成→Scene Builderで編集、という流れ。
AnchorPaneはデフォルトでは子要素のサイズに自動で調整される。
Pane（ペイン）は、ボタンやラベルなどのUI部品（ノード）をまとめて配置・管理するレイアウトコンテナ。

作りたい感じ
右と左に分かれていて、左でフォルダ選択、ファイル検索
右でテキストを表示
左の部分はフォルダが並ぶところとファイルが並ぶところに分かれている
フォルダを選択→フォルダ名が出てくる
フォルダ名が縦に並んで行って、量が増えるとスクロールできる

aiにレイアウトを考えてもらって、基礎になるレイアウトを配置した
